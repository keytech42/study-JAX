    JAX Deep Dive: Pre-LN vs Post-LN의 수학적 증명 (기울기 붕괴의 역학)

    이 문서는 이전 문서(Transformer Block Wiring)에서 정성적으로만 다루었던 "Post-LN 구조에서 층이 깊어질수록 왜 기울기(Gradient)가 폭발하거나 소실되는가?"를 증명한다.

    단, 수학적 배경이 완벽하지 않은 독자도 직관적으로 이해할 수 있도록, 미적분학의 핵심 개념(연쇄 법칙, 야코비안 행렬, 노름)을 먼저 일상적인 비유로 풀어낸 뒤 소진적(Exhaustive)인 증명으로 진입한다.

    1. 수식 읽기: 딥러닝을 위한 미적분학 직관

    본격적인 증명에 앞서, 우리가 사용할 세 가지 수학적 도구의 '느낌'을 잡아보자.

    1) 연쇄 법칙 (Chain Rule): 오차의 전달

    연쇄 법칙은 톱니바퀴들이 맞물려 돌아가는 것과 같다. A 톱니바퀴가 한 바퀴 돌 때 B 톱니가 2바퀴 돌고, B가 한 바퀴 돌 때 C가 3바퀴 돈다면? A가 한 바퀴 돌면 C는 총 \(2 \times 3 = 6\) 바퀴를 돈다. 딥러닝에서 역전파(Backpropagation)는 맨 끝단(Loss)에서 발생한 오차를 맨 처음 층까지 전달하는 과정이다. 각 층(톱니바퀴)이 오차를 얼마나 증폭시켰는지(혹은 축소시켰는지)를 모두 곱해서 맨 앞단에 도달하는 것이 연쇄 법칙이다.

    2) 야코비안 행렬 (Jacobian Matrix): 다차원 공간의 돋보기

    고등학교 미적분에서 \(y = 3x\)를 미분하면 3이다. 이는 \(x\)가 1만큼 변할 때 \(y\)는 3만큼 변한다는 뜻이다. 하지만 딥러닝에서 데이터는 단순한 숫자(\(x\))가 아니라 수백 개의 숫자가 모인 '벡터(Vector)'다. "입력 벡터가 미세하게 꿈틀거릴 때, 출력 벡터는 어느 방향으로 얼마나 요동치는가?"를 거대한 표(행렬)로 정리해 놓은 것이 바로 야코비안 행렬(\(J\))이다. 즉, 야코비안 행렬은 "해당 층(Layer)이 오차 신호를 얼마나 뻥튀기하거나 찌그러뜨리는지"를 나타내는 증폭기(Amplifier)의 스펙표다.

    3) 행렬 노름 (Matrix Norm): 행렬의 덩치

    야코비안 행렬 안에는 수많은 숫자가 들어있다. "그래서 이 행렬은 전체적으로 값이 얼마나 큰 건데?"라고 물었을 때, 행렬의 전체적인 덩치(영향력)를 하나의 숫자(스칼라)로 요약해 주는 함수가 노름(Norm)이다. 야코비안 행렬의 노름이 \(1\)보다 크면 기울기가 폭발(Exploding)하고, \(1\)보다 작으면 기울기가 소실(Vanishing)된다고 이해하면 된다. 우리의 목표는 이 크기가 최대한 \(1\)(\(\approx I\), 단위 행렬)을 유지하도록 아키텍처를 짜는 것이다.

    2. 층이 깊어지면 분산(Variance)은 왜 커지는가?

    본격적인 수식에 들어가기 앞서, 트랜스포머가 층을 통과할 때마다 데이터의 덩치(분산)가 어떻게 변하는지 알아보자. 잔차 연결(Residual Connection)의 수식은 \(x_{new} = x_{old} + F(x_{old})\) 다.

    • \(x_{old}\): 기존 데이터 (고속도로)
    • \(F(x_{old})\): 새로운 정보 (옆길에서 계산된 값)

    통계학에서 서로 독립적인 두 변수를 더할 때, 전체 분산은 각 변수의 분산의 합이 된다 (\(V(A+B) = V(A) + V(B)\)). 즉, 층(Layer)을 하나 지날 때마다 기존 데이터에 새로운 정보가 '더해지므로', 데이터가 가지는 변동성(분산, Variance)은 층의 개수 \(L\)에 비례하여 점점 커지게 된다. 분산이 \(L\)에 비례하여 커지면, 데이터의 흩어짐을 나타내는 표준편차 \(\sigma\)는 \(\sqrt{L}\)에 비례하여 커진다.

    3. Post-LN의 수학적 해체 (왜 실패했는가?)

    초기 트랜스포머가 채택했던 Post-LN의 수식을 \(l\)번째 층에 대해 써보자. (편의상 Sublayer를 \(F\)로 표기한다.)

    \[ x_{l+1} = \text{LayerNorm}(x_l + F_l(x_l)) \]

    이제 이 식을 \(x_l\)에 대해 미분하여 야코비안 증폭기 비율을 구해보자. LayerNorm 함수 자체의 야코비안을 \(J_{LN}\)이라고 하면 연쇄 법칙에 의해 다음과 같이 전개된다.

    \[ \frac{\partial x_{l+1}}{\partial x_l} = J_{LN} \cdot \frac{\partial (x_l + F_l(x_l))}{\partial x_l} $$ $$ \frac{\partial x_{l+1}}{\partial x_l} = J_{LN} \cdot \left( I + \frac{\partial F_l(x_l)}{\partial x_l} \right) \]

    치명적인 수학적 병목: LayerNorm의 야코비안 \(J_{LN}\)

    LayerNorm은 데이터를 평균 0, 분산 1로 억누르는 정규화 함수다. 입력 데이터의 크기(표준편차 \(\sigma\))가 크면 클수록, 이를 1로 맞추기 위해 강하게 짓눌러야(나누어야) 한다. 수학적으로 볼 때, LayerNorm의 야코비안 행렬 크기(노름)는 입력 텐서의 표준편차에 정확히 반비례(\(\propto \frac{1}{\sigma}\))하게 된다.

    자, 이제 순전파(Forward Pass)와 역전파(Backward Pass)가 만나는 재앙을 상상해 보자. 1. 순전파: 앞서 설명했듯, 데이터가 층을 지나며 더해질수록 맨 끝단(출력단)의 분산은 기하급수적으로 커지고, 표준편차 \(\sigma\)는 \(\sqrt{L}\)에 비례하여 거대해진다. 2. 역전파: 거대해진 데이터를 억누르기 위해 LayerNorm은 엄청난 힘으로 데이터를 나눴을 것이다. 이로 인해 끝단 층들의 야코비안 \(J_{LN}\) 크기는 \(\frac{1}{\sqrt{L}}\)에 비례하여 엄청나게 작아져 버린다.

    결론적으로, 맨 끝단에서 발생한 오차가 맨 앞단으로 전달될 때, 각 층을 지날 때마다 작은 값(\(\frac{1}{\sqrt{L}}\))이 연쇄적으로 곱해진다. 기울기는 대략 \(\left(\frac{1}{\sqrt{L}}\right)^L\) 이라는 끔찍한 비율로 소실(Vanishing)된다. \(L=100\)층만 되어도 맨 앞단은 아무런 학습 신호(오차 피드백)를 받지 못하고 붕괴(Collapse)해버리는 것이다.

    제약(Constraint) vs 관례(Convention): Learning Rate Warm-up

    이 기울기 소실을 막기 위해 구글은 초기 학습률을 0으로 둔 뒤 아주 서서히 올리는 Learning Rate Warm-up 기법을 사용했다. 이것은 우아한 수학적인 해법이 아니라, 기울기가 붕괴하는 극초기 상태를 억지로 모면하기 위해 도입한 임시방편적 꼼수(Pragmatic Hack)에 불과했다. 아키텍처 자체가 결함을 안고 있었던 것이다.

    4. Pre-LN의 수학적 구원 (왜 성공했는가?)

    이제 최신 트랜스포머가 채택한 Pre-LN의 수식을 보자. 정규화(LayerNorm)를 덧셈 바깥이 아니라, 덧셈 안쪽(옆길)에만 적용했다.

    \[ x_{l+1} = x_l + F_l(\text{LayerNorm}(x_l)) \]

    마찬가지로 이 식을 \(x_l\)에 대해 미분하여 야코비안을 구해본다. 덧셈을 기준으로 미분이 나뉜다.

    \[ \frac{\partial x_{l+1}}{\partial x_l} = \frac{\partial x_l}{\partial x_l} + \frac{\partial F_l(\text{LayerNorm}(x_l))}{\partial x_l} $$ $$ \frac{\partial x_{l+1}}{\partial x_l} = I + \frac{\partial F_l}{\partial \text{LN}} \cdot J_{LN} \]

    비교 분석: 야코비안 구조의 극적인 변화

    Post-LN의 수식이 \(J_{LN} \cdot (I + \dots)\) 형태여서 전체 행렬이 \(J_{LN}\)의 작은 크기에 묶여서 지배당했던 반면, Pre-LN의 수식에서는 단위 행렬 \(I\) (Identity Matrix)가 완전히 독립적으로 덧셈 밖으로 빠져나와 있다!

    이것이 의미하는 바는 엄청나다. 연쇄 법칙으로 \(N\)개의 층을 연달아 곱해보자.

    \[ \prod_{l=1}^{N} \left( I + \frac{\partial F_l}{\partial \text{LN}} \cdot J_{LN} \right) \]

    수식을 전개해보면 항상 \(I + (\text{나머지 찌꺼기들})\) 형태가 유지된다. 단위 행렬 \(I\)는 1과 같아서 100번을 곱해도 그대로 \(I\)다. 즉, 오차 기울기가 역전파될 때, 어떠한 층의 분산이나 LayerNorm의 축소 효과(\(J_{LN}\))에도 방해받지 않고 \(I\)라는 완벽하게 보존된 1:1 고속도로를 타고 1번째 층까지 직행한다!

    이 수학적 성질(단위 행렬 \(I\)의 덧셈 분리) 덕분에 Pre-LN 구조는 층이 수십, 수백 개로 깊어져도 초기 기울기가 붕괴하지 않는다. 따라서 귀찮고 불안정한 Warm-up 꼼수 없이도 즉시 거대한 학습률(Learning Rate)을 적용하여(Scale-up) 안정적으로 훈련할 수 있게 된 것이다.

    5. 프레임워크 생태계: JAX, PyTorch는 이를 어떻게 다루는가?

    이러한 아키텍처적 진화(Pre-LN의 표준화)는 JAX나 PyTorch 같은 프레임워크의 미분 엔진 자체를 바꾸지는 않는다. 프레임워크의 Autograd는 \(x + F(LN(x))\) 든 \(LN(x + F(x))\) 든 개발자가 짠 수식 그대로 기계적으로 야코비안 연쇄 법칙을 수행해 줄 뿐이다.

    하지만 커뮤니티의 기본 제공 API(Standard Library)의 형태를 완전히 바꾸어 놓았다.

    프레임워크 라이브러리의 진화

    • PyTorch의 nn.TransformerEncoderLayer: 초기에는 구글의 원본 논문을 따라 철저히 Post-LN 방식으로 하드코딩되어 있었다. 하지만 층을 깊게 쌓으려는 개발자들이 기울기 붕괴로 고통받자, PyTorch는 1.9 버전부터 부랴부랴 norm_first=True라는 파라미터를 추가하여 Pre-LN 모드를 지원하기 시작했다.
    • JAX / Haiku / Flax: JAX 생태계의 신경망 라이브러리들은 구글 원본 논문의 잔재(Post-LN)를 버리고, 우리가 src/transformer.py에서 구현한 것처럼 클래스 내부에서 명시적으로 정규화를 먼저 호출(query=layer_norm(x))하는 함수형 조합을 기본 예제로 강력하게 권장하고 있다.

    결론적으로, 딥러닝에서 '더하기(+)의 순서' 하나를 괄호 안팎으로 바꾸는 것은 단순한 취향의 차이가 아니다. 역전파 야코비안 행렬의 전개식을 완전히 뒤바꾸어, \(\frac{1}{\sqrt{L}}\)의 저주에 갇힐 것인가, 아니면 단위 행렬 \(I\)의 고속도로를 탈 것인가를 결정하는 고도의 수학적 설계인 것이다.
